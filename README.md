## 🎮 About the Project

What happens when a signal disappears in the vastness of space?

**Signal Lost — The Final Transmission** is an experimental 3D game project that brings a science-fiction concept to life in the browser. The project focuses on creating an immersive visual environment and an interactive gaming experience without requiring a traditional game launcher.

## 💻 Run Locally

You can run the project locally without a separate build pipeline.

1. Clone the repository:

   ```bash
   git clone https://github.com/rizzhub3118/SignalLost.git
   ```

2. Enter the project directory:

   ```bash
   cd SignalLost
   ```

3. Start a local server using Python:

   ```bash
   python -m http.server 8000
   ```

4. Open this URL in your browser:

   ```text
   http://localhost:8000/index.html
   ```

Alternatively, open `index.html` directly in a browser if the project works in your environment that way.

## 🎙️ Built with a Voice-First Workflow

Signal Lost was developed as an experiment in voice-driven software development. Wispr Flow was used for voice dictation, with GitHub Copilot Chat assisting with code generation and iteration.

The project explores how natural-language input and AI-assisted coding can help turn a game idea into a playable browser experience.
